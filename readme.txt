SMART HOME GUARDIAN

This submission contains:

1. Dissertation Report (PDF)
2. Executable Application (SmartHomeGuardian_v1.exe)
3. Source Code
4. Supporting Files and Models
5. Ethical Approval Documentation

The executable represents the final tested version used during evaluation and testing activities described within the dissertation.

The source code is included for inspection and verification purposes.
